Strata Decisions API

A Jev-compatible "System One" decision endpoint built into the local Strata server. It answers typed questions about a piece of input state with a probability distribution and a confidence value, instead of free-text output.

Endpoints

MethodPathPurpose
POST/v1/systemonePrimary endpoint
POST/v1/decideAlias of /v1/systemone

Base URL on this machine: http://10.0.0.18:8080 (or http://127.0.0.1:8080). Decisions run on the local model (qwen3.8-flash-next-iq3_s, 256K context).

Authentication

Every call must include the API key as a bearer token:

Authorization: Bearer <API_KEY>

The key is stored on the desktop in the file /home/max/Desktop/API- Strata. Requests without a valid key get 401 authentication_error. /health on port 8080 is public and does not need a key.

Request

Send a JSON object with a state and typed questions:

{
  "model": "jev-latest",                                  // optional; ignored, runs on the local model
  "state": "Customer was charged twice and nobody replied for 3 days.", // string, object, or array
  "questions": {
    "route":    { "type": "choice", "instructions": "...", "criteria": { ... } },
    "urgency":  { "type": "score",  "instructions": "...", "criteria": [ ... ] },
    "escalate": { "type": "noul",   "instructions": "..." }
  }
}

Question types

typecriteriaAnswer fields
choice Object of labels to short descriptions (or null), 1–255 options choice, probabilities, confidence
score Ordered list of 2–10 level descriptions (low to high) score, legend, probabilities, confidence
noul Optional; may hold "true" / "false" descriptions noul (no confidence field)

Every question needs instructions: what the model should decide. Generic "which is the best option?" text works, but specific instructions produce better-calibrated answers.

Response

{
  "model": "qwen3.8-flash-next-iq3_s",
  "answers": {
    "route": {
      "type": "choice", "choice": "billing",
      "probabilities": { "billing": 0.7, "bug": 0.1, "account": 0.2 },
      "confidence": 0.7
    },
    "urgency": {
      "type": "score", "score": 2.3,
      "legend": ["routine", "today", "urgent", "critical"],
      "probabilities": { "0": 0.0, "1": 0.1, "2": 0.5, "3": 0.4 },
      "confidence": 0.5
    },
    "escalate": { "type": "noul", "noul": 0.8 }
  },
  "usage": { "input_tokens": 671, "output_tokens": 173 }
}
FieldMeaning
answers.<name>.confidenceThe winning probability for choice/score answers (highest value after normalization).
scoreProbability-weighted position on the level scale, 0 = first list entry, n-1 = last.
noulProbability the answer is yes, from 0 to 1.
probabilitiesNormalized to sum to 1 for choice and score.

These are the model’s own probability estimates, not outputs of a separately calibrated classifier. Gate decisions on confidence, and pick thresholds that fit your use case.

Worked example (cURL)

KEY="$(cat "/home/max/Desktop/API- Strata")"

curl -s -X POST http://10.0.0.18:8080/v1/decide \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{
    "state": "Customer: \"I paid for a 2-month plan but the account shows 1 month, and support chat has been silent for 3 days.\"",
    "questions": {
      "route":   { "type": "choice", "instructions": "Which team owns this?",
                   "criteria": { "billing": "payments and amounts", "bug": "a product defect", "account": "login and plan status" } },
      "urgency": { "type": "score", "instructions": "How urgent is this for the customer?",
                   "criteria": ["routine", "today", "urgent", "critical"] },
      "escalate":{ "type": "noul", "instructions": "Should a human supervisor step in now?" }
    }
  }'

Errors

Statuserror.typeWhen
400invalid_request_errorMalformed request, bad question type, empty criteria, too many choice options (>255), fewer than 2 or more than 10 score levels, missing instructions.
400max_tokens_exceededInput over Jev’s budgets: 32,000 tokens for the state plus the longest question, or 64,000 tokens for the whole request.
401authentication_errorMissing or invalid Authorization: Bearer key.
409busy_errorA request is already running on the single local model.
502structured output errorThe model answered but the result could not be validated against the schema.
503try again laterThe engine is busy warming up or loading.

Notes

  • Questions are answered in a single model generation inside one JSON object, then validated against a strict JSON schema.
  • The endpoint is served by the Strata server, so it is available whenever Strata is running (use the desktop Strata Start shortcut).
  • Input budgets follow Jev’s: keep each decision context under ~32K tokens, or split the state across multiple calls.
